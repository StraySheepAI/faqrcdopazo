¿Cómo guardar los cambios?
Flujo de trabajo:
  1. Editá las preguntas y respuestas acá arriba.
  2. Apretá "↓ Exportar faq-data.json" — se descarga el archivo.
  3. Reemplazá el faq-data.json en tu repo de GitHub con el nuevo.
  4. Vercel lo deploya automáticamente. Listo.
